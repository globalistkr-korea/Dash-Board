# 영업이익 악화 TOP 5

- 경영실적 → 월간 비교의 손익 표 아래에 고객사·창고 순위를 별도로 표시한다. 매출 규모와 무관하게 비교 기간의 영업이익 감소액이 큰 순으로 최대 5건을 보여준다.
- 경영실적의 전월비·전년동월비·누계 전년비 기간과 지역·사업 조건을 그대로 사용한다. CL의 WM/TM은 창고/운송으로 매핑하며, 원본이 구분하지 않는 세부 사업은 범위를 넓히지 않고 안내한다.
- 기간 양쪽의 선택 월에 영업이익이 입력된 대상만 비교한다. 행 없음·미입력은 0으로 채우지 않는다. 여러 사업 구분의 행이 있는 월에는 포함된 행 집계별 입력 상태를 확인한다. 매출이 양수이고 필요한 값이 모두 있을 때만 영업이익률을 계산한다.
- 판관비 = 매출이익 − 영업이익, 매출원가 = 매출 − 매출이익. 이익률은 기간 합계의 비율이며 증감은 %p로 표시한다. 고객사와 창고는 같은 원본의 서로 다른 집계 기준이므로 합치지 않는다.
- 이름을 누르면 같은 화면에서 동일한 기간·범위의 전후 손익을 표시하고 기존 의사결정 조치 등록과 연결한다. 수치는 원본 스냅샷을 사용하며 수집 일정과 원본은 변경하지 않는다.
- 34개 Node 테스트, ESLint, 빌드, 1~9월 누계 및 북부 CL/TM 전월비 상세, 390px에서 표 내부 스크롤을 확인했다.
