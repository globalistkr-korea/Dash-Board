# 표시 통화 전환

- 상단 한/EN 옆 원/동 전환. 기본 VND, LocalStorage vn_dashboard_currency에 선택 저장.
- 원본 데이터·비교·원가율·임계값·사유 저장은 백만동 기준 유지. 통화는 표시만 환산.
- 원화 환산은 기존 참고 고정율 1 VND = 0.056 KRW. 실시간 환율 아님을 상단 안내. 최신 환율처럼 표현하지 말 것.
- 매출·매출원가: 십억동/억원. 이익·원가항목·보고문구·TOP5: 백만동/백만원.
- 직접 원본 전표를 문의하는 질문은 원본 VND 금액 유지해 환산값과 혼동 방지.
- currency.js 외부 저장소를 LangProvider에서 useSyncExternalStore로 구독. 선택 변경 시 표·보고문구·복사 텍스트 모두 재렌더링.
