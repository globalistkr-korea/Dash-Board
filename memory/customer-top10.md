# 고객사 누계 TOP 10 (2026-10-21)

- 요청: 경영실적 전체 기간과 같은 방식으로 고객사별 누계 매출 TOP 10 / 누계 이익 TOP 10 및 전년 동일기간 비교를 표시한다.
- 고객사 목록 상단에 두 표를 분리했다. 이익 기본은 매출이익이며 영업이익 전환을 제공한다. 각 표는 해당 지표의 당년 누계 내림차순 독립 순위다.
- `누적`은 해당 연도 실적 월 전체(현재 2026년 1~8월), 개별 월 선택은 1월~선택 월이다. 고객사 목록의 개별 월 표시 동작은 유지하며, 순위 표에는 누계 기준을 명시한다.
- 지역·사업·운송/창고·검색 조건을 순위에도 적용한다. 매출 비중은 TOP 10 합계가 아닌 현재 조건 전체 고객의 입력 누계 매출을 분모로 한다.
- TOP 10은 단월 활동 필터 적용 전 데이터를 사용한다. 선택 월에 행이 없어도 그 이전 실적이 있는 고객은 누계 순위에 포함한다.
- 전년 동일기간 금액·증감액·증감률, 매출 비중 또는 이익률, 입력 개월 상태를 표시한다. 기존 `cumulativeComparison`과 필드 입력 여부를 공유한다. 미입력/행 없음은 실제 입력 0과 구분한다.
- 일부 월 입력 금액은 입력 소계로 표시하고 입력 개월을 안내한다. 당년/전년 모두 전체 비교 기간이 입력된 경우에만 증감을 계산한다. 전년 0은 증감액만 계산하며 비율은 공란이다. 음수 전년 비율의 분모는 절댓값이다. 이익률은 완전 입력된 누계 이익 / 누계 매출이다.
- 과거 지역 구분이 없는 2023·2024년을 북부/남부 전년 값으로 대입하지 않는다. 전체 지역에서만 해당 연도 원본 범위로 비교한다.
- 고객사 클릭은 기존 상세 분석으로 바로 이동한다. 휴대폰에서는 표 내부 가로 스크롤 및 고객사 열 고정을 사용한다. 한국어/영어/베트남어, 기존 통화 전환을 지원한다.
- 원본과 고객사 별칭 규칙은 변경하지 않았다. 사용자 확인된 SPIN MASTER 연결을 재사용한다. DIANA 등의 미확정 이름이나 전년 입력 부족은 `전년 자료 확인`/입력 개월로 표시하며 임의 병합·0 대입·신규 고객 판정을 하지 않는다.
- 원본 수집, 수집 일정, 인증, Firestore 데이터 구조는 변경하지 않는다. 수집은 계속 사용자 요청 시에만 실행한다.
