# 전년 동일기간 누계 비교 (2026-10-14)

- 고객사·창고 상세 화면의 기존 월별 손익 표 위에 동일기간 누계 비교표를 추가했다. 매출·직접원가·직접이익·간접원가·매출이익·영업이익과 영업이익률을 비교한다.
- 누적 선택 시 당년 원본 집계 월까지(현재 2026년 8월 → 양년 1~8월), 특정 월 선택 시 1월~선택 월을 비교한다. 전년 전체 연간 실적이나 전년 단일 월로 바꾸지 않는다. 새 수집 시 actualMonths 기준이 자동으로 따라간다.
- 양년의 해당 지표가 같은 개월 전체 입력된 경우에만 증감액·증감률을 계산한다. 일부 월 입력은 확인된 합계 + 입력 개월/기준 개월 표시, 증감은 비움. 행 없음·미입력·전년 자료 없음·기록된 0을 구분한다. 매출 0일 때 영업이익률을 생성하지 않는다.
- 증감률=(당년−전년)/|전년|, 전년이 0이면 증감액만 표시한다. 영업이익률은 누계 영업이익/누계 매출, 차이는 %p이며 월 이익률 평균이 아니다. 원가는 증가를 빨강·감소를 파랑, 이익·매출은 증가를 파랑·감소를 빨강으로 표시한다.
- 기존 월별 표와 월평균 계산은 유지. 원화/VND·한국어/영어/베트남어·지역·사업·상세 구분에 맞춰 비교표가 바뀐다. 0이 아닌 작은 값은 표시 자리수를 늘려 실제 입력 0과 혼동을 줄인다. 모바일에서 양년 금액을 우선 보이며 표 내부 가로 스크롤로 증감을 확인한다.
- 사용자에게 동일 고객사를 확인받았다: `SPIN MASTER`(2026) ↔ `SPIN MASTER TOYS FAR EAST LIMITED (북부)`(2025). 원본 JSON 키·이름·수치는 보존하고 분석 뷰에서만 연결한다. 북부 FF(3320080004), 운송(3320081001/3320081007)만 허용한다. 신규 Cost Center·다른 사업·다른 지역은 연결을 거부한다. `SPIN MASTER TOYS FAR EAST LIMITED (미지정)`의 2024 실적은 합치지 않는다.
- 과거 원본 이름 검색도 SPIN MASTER 상세로 연결되며 연도 선택 시 해당 연도 월별 실적을 그대로 볼 수 있다. 다른 고객사는 이름 유사도·Cost Center만으로 자동 연결하지 않는다.
- 원본 수집은 요청 시만 유지했고 이번에 새 수집은 하지 않았다. Firestore/Auth 규칙·개인 의사결정 자료를 변경하지 않았다.
- 검증: Node 계산/명칭 연결 테스트 15개, lint/build, 양년 동일기간·불완전 입력·기록된 0·음수 전년·가중 이익률·다른 사업/지역/Cost Center 차단·원본 및 전체 월별 금액/원가 항목 합계 보존. 고객사/창고 상세, 조회 월, 과거 연도, 원본 이름 검색, 통화/언어 전환, 390px 모바일 검증.
