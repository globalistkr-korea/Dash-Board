# 경영실적 월 선택 ‘전체’ (2026-10-21)

- 월간 비교의 월 선택 맨 앞에 `전체(1~집계월)`을 추가했다. `month=0`을 전체 선택으로 저장한다. 집계월은 plan3y.actualMonths에서 읽으며 신규 수집으로 8→9월이 되면 전체 선택은 그대로 1~9월을 사용한다.
- 기존 `vn_dashboard_monthly_view_pnl_v2` 키와 요약/점검/상세 선택은 유지한다. 기존 단일 월 선택은 호환되며 새로 시작하면 전체가 기본이다. null·잘못된 저장값은 전체로 복구한다. 전체 상태에서 연도 변경 시 해당 연도 집계기간 전체가 된다.
- 전체 선택 시 전월비·전년동월비를 비활성화하고 `전년 동일기간 누계`로 자동 전환한다. 당월 표 대신 양년의 같은 기간 누계·증감액·전년비 표를 보여준다. 이후 단일 월을 선택하면 전년동월비로 돌아가며 전월비/누계 선택도 가능하다.
- `monthlyPeriod.js`의 비교 기간 객체 하나를 숫자 표와 VarianceCard/ReportBriefing 분석에 함께 전달한다. 전체 2026년 1~8월은 전년 2025년 1~8월이며 전년 연간이나 전년 8월만 비교하지 않는다. 단일 월의 전년동월비 분석도 같은 비교 객체를 사용하도록 맞췄다.
- 전년 자료가 없거나 같은 지역 구분이 없는 2025년 북부/남부 등은 기존 제한을 유지하며 전년을 0으로 대신하지 않는다. 전년도 수집기간이 더 짧아도 누계 비교를 생성하지 않는다. 전년 0은 증감액만 표시하고 증감률은 비운다.
- 입력 실적 합계는 해당 연도 집계월까지로 제한한다. 미래 입력·계획값을 전체 실적으로 넣지 않는다. 원본 수집은 요청 시만 유지하며 이번 변경에서는 원본을 새로 수집하거나 금액을 수정하지 않았다. 개인 메모·Firestore/Auth 규칙도 변경하지 않았다.
- 계산 테스트 6개 추가, 기존 15개 포함 21개 통과. CL/TM/북부 실제 원본 합계 대조, 요약/점검/상세 같은 합계 및 분석 기간 확인, 전체 저장/재조회, 단일 월 전환, 연도에 따른 전체 기간 변경, 모바일 390px 가로 넘침 없음 확인.
