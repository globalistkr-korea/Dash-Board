# 의사결정·후속조치 보드 (2026-10-08)
- 의사결정 탭, 개인별 decisionBoards/{uid}/items/{id}, 기존 허용 이메일 정책 적용.
- 6단계 보고, 담당자/기한, 후속조치 완료, 검색/필터, 보고 복사(iOS 폴백).
- 입력은 uid별 로컬 임시저장. 저장 버튼으로 cloud transaction + revision history 동시 기록.
- 다기기 충돌 시 덮어쓰지 않고 작성본 보존. 완료/보관 상태로 기록 유지.
- 한국어/English/Tiếng Việt UI; 사용자 입력 본문은 번역·생성하지 않음.
